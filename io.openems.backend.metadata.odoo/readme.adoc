= Metadata Odoo

Metadata OpenEMS Backend implementation for https://github.com/odoo/odoo[Odoo]. 

Enables you to manage multiple edges with one backend.	 


[NOTE]
====
* This bundle targets Odoo 18 and Odoo 20; names that differ between them (groups field of
`res.users`, session-expired error) are handled. For a seamless integration of Odoo
and OpenEMS the open-source https://github.com/OpenEMS/odoo-openems[Odoo-OpenEMS] module is needed.
* `odooPassword` is used for the session login (`/web/session/authenticate`) and for XML-RPC
(`/xmlrpc/2/object`). Odoo accepts no API key for the session login, so it must be the password of
the user `odooLogin`. Odoo 20 accepts API keys for RPC only with scope `rpc`, Odoo 18 also keys
without scope. Where API keys are used against Odoo 20, check after the upgrade that they have
scope `rpc`, otherwise create new keys with scope `rpc`.
====
