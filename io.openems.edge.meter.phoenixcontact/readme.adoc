= Phoenix Contact EEM-XM Meter

Three-phase electricity meter for energy measurement via Modbus protocol.

== Overview

This bundle provides integration with Phoenix Contact energy meters, specifically the EEM-XM series (EEM-XM157/355/357/375/377). The component communicates with the meter through the Modbus protocol (reading Float input registers, function code 04), enabling real-time energy monitoring and comprehensive data collection in OpenEMS.

Phoenix Contact meters are designed for reliable energy measurement in commercial and industrial applications with robust industrial design and proven reliability.

== Supported Devices

* https://www.phoenixcontact.com/[Phoenix Contact EEM-XM series (EEM-XM157/355/357/375/377) icon:external-link[]]

== Components

This bundle implements the following OpenEMS Component:

=== Phoenix Contact Meter

*Name*: Meter Phoenix Contact

*Factory-PID*: `Meter.PhoenixContact`

.Implemented Natures/Interfaces
* PhoenixContactMeter
* ElectricityMeter
* ModbusComponent
* OpenemsComponent
* ModbusSlave

*Description*: Three-phase electricity meter for energy measurement via Modbus protocol.

.Additional Channels (beyond the standard ElectricityMeter)
* `VOLTAGE_L1_L2`, `VOLTAGE_L2_L3`, `VOLTAGE_L3_L1`: line-to-line voltages (used under 3P4W and 3P3W wiring; under 3P3W the standard `VOLTAGE_L1/L2/L3` channels are derived from these as L-L / √3, assuming a symmetrical system)
* `VOLTAGE_HARMONIC_DISTORTION_L1/L2/L3`, `CURRENT_HARMONIC_DISTORTION_L1/L2/L3`: voltage and current total harmonic distortion per phase (3P4W; L1 only under 1P2W)
* `VOLTAGE_HARMONIC_DISTORTION_L1_L2`, `VOLTAGE_HARMONIC_DISTORTION_L2_L3`: line-to-line voltage total harmonic distortion (3P3W only)
* `POWER_FACTOR`: total power factor (all wirings)
* `POWER_FACTOR_L1/L2/L3`: per-phase power factor (3P4W; L1 only under 1P2W)
* `PHASE_ANGLE`: total phase angle U-I (all wirings)
* `PHASE_ANGLE_L1/L2/L3`: per-phase phase angle U-I (3P4W; L1 only under 1P2W)
* `REACTIVE_LAGGING_ENERGY`, `REACTIVE_LEADING_ENERGY`: cumulative lagging (inductive) and leading (capacitive) reactive energy

.*Configuration*:
* `id` (String): Component ID for unique identification (default: "meter0")
* `alias` (String): Human-readable alias for the component
* `enabled` (Boolean): Enable/disable this component (default: true)
* `modbus_id` (String): ID of Modbus bridge for communication (default: "modbus0")
* `modbusUnitId` (Integer): Modbus Unit ID of the meter device (default: 1)
* `type` (Enum): Meter type - GRID, PRODUCTION, or CONSUMPTION (default: PRODUCTION)
* `phaseWiring` (Enum): Phase wiring - THREE_PHASE_FOUR_WIRE (3P4W, reads L-N and L-L voltages and per-phase powers), THREE_PHASE_THREE_WIRE (3P3W, reads L-L voltages and total powers only; phase voltages are derived as L-L / √3) or SINGLE_PHASE_TWO_WIRE (1P2W, e.g. EEM-XM157, reads L1 values only) (default: THREE_PHASE_FOUR_WIRE)
* `invert` (Boolean): Invert power and current, swap production/consumption and lagging/leading energy (default: false)
