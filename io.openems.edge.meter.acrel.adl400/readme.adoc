= Acrel ADL400 Meter

Three-phase electricity meter for energy measurement via Modbus protocol.

== Overview

This bundle provides integration with Acrel ADL400 smart meters. The component communicates with the meter through the Modbus RTU protocol (reading holding registers, function code 03), enabling real-time energy monitoring and comprehensive data collection in OpenEMS.

The driver maps the meter's *primary-side* registers for voltage, current, power and energy, so any configured CT/PT transformer ratios are already applied by the meter and no additional scaling is needed in OpenEMS. Voltage/current/frequency/power-factor are read as IEEE-754 floats (word order LSWMSW, the meter's native order; note the OpenEMS default is MSWLSW, hence the explicit override); total active/reactive energy is read as INT32 with 0.1 kWh resolution. Voltage/current harmonic distortion and per-phase/total power factor are exposed via custom channels. Under 3P3W wiring the phase voltages (L-N) are derived from the line-to-line voltages (divided by √3).

== Supported Devices

* Acrel ADL400 three-phase energy meter

== Components

=== Acrel ADL400 Meter

*Name*: Meter Acrel ADL400

*Factory-PID*: `Meter.Acrel.Adl400`

.Implemented Natures/Interfaces
* AcrelAdl400Meter
* ElectricityMeter
* ModbusComponent
* OpenemsComponent
* ModbusSlave

.Additional Channels (beyond the standard ElectricityMeter)
* `VOLTAGE_L1_L2`, `VOLTAGE_L2_L3`, `VOLTAGE_L3_L1`: line-to-line voltages (read under both wiring modes; under 3P3W they are also used to derive the phase voltages)
* `VOLTAGE_HARMONIC_DISTORTION_L1/L2/L3`, `CURRENT_HARMONIC_DISTORTION_L1/L2/L3`: voltage and current total harmonic distortion per phase
* `POWER_FACTOR`, `POWER_FACTOR_L1/L2/L3`: total and per-phase power factor (3P4W only; not available under 3P3W wiring)
* `REACTIVE_LAGGING_ENERGY`, `REACTIVE_LEADING_ENERGY`: cumulative lagging (inductive) and leading (capacitive) reactive energy

.*Configuration*:
* `id` (String): Component ID for unique identification (default: "meter0")
* `alias` (String): Human-readable alias for the component
* `enabled` (Boolean): Enable/disable this component (default: true)
* `modbus_id` (String): ID of Modbus bridge for communication (default: "modbus0")
* `modbusUnitId` (Integer): Modbus Unit ID of the meter device (default: 1)
* `type` (Enum): Meter type - GRID, PRODUCTION, or CONSUMPTION (default: PRODUCTION)
* `phaseWiring` (Enum): Phase wiring - THREE_PHASE_FOUR_WIRE (3P4W, reads L-N and L-L voltages, per-phase powers and power factors) or THREE_PHASE_THREE_WIRE (3P3W, reads L-L voltages and total powers only; phase voltages are derived from L-L / √3) (default: THREE_PHASE_FOUR_WIRE)
* `invert` (Boolean): Invert power and current, swap production/consumption and lagging/leading energy (default: false)
